# Changelog

## 0.1.0 — 2026-11-13

First public version.

- Decision protocol (DEC-01 to DEC-09) placed before all visual rules.
- Principles: Apple's eight design principles (HIG, June 2026), the Liquid Glass visual principles, the WWDC17 working vocabulary, and an order for resolving conflicts.
- UI rules: layout and spacing (LAY), typography (TYP), colour and contrast (COL), shape, depth and materials (SHP), motion (MOT).
- UX rules: interaction and targets (INT), feedback and states (FBK), navigation and structure (NAV), writing (WRT), accessibility (ACC), trust and privacy (TRU).
- `tokens/tokens.json` holds the checkable values; `checklists/review.md` holds the review pass.
- Every rule carries a strength (MUST / SHOULD / MAY) and an evidence level (standard / platform / research / craft / taste).
